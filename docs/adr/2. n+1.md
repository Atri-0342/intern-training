## N+1 Query Problem

### N+1 Approach

The N+1 pattern performs one initial query to retrieve records, followed by one additional query for each record.

For 100 patients:

- 1 query retrieves the 100 patient IDs.
- 100 additional queries retrieve each patient's scan count.
- Total: 101 database queries.

Result:

- Queries: 101
- Time: 0.883933 seconds

### Optimized JOIN Approach

The N+1 approach was rewritten using a single SQL query with a `LEFT JOIN`.

    SELECT
        p.synthetic_study_id,
        COUNT(s.id) AS scan_count
    FROM patients p
    LEFT JOIN scans s
        ON s.patient_id = p.synthetic_study_id
    GROUP BY p.synthetic_study_id
    LIMIT 100;

Result:

- Queries: 1
- Rows returned: 100
- Time: 0.105349 seconds

### Comparison

N+1 with 101 queries and time is 0.883933 s

Single JOIN with 1 queries and time is 0.105349 s

The single JOIN approach was approximately 8.39× faster in this measurement.

### Conclusion

For this experiment, replacing the N+1 pattern with a single JOIN reduced the number of queries from 101 to 1 and reduced the measured time from 0.883933 seconds to 0.105349 seconds.
